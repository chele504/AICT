# AICT 问卷评分体系

本文档用于构建“AI+文旅应用成效评价”问卷评分体系，可直接用于游客问卷、项目调研问卷或课题材料中的评价指标设计。

## 1. 评分目标

本问卷用于评价 AI 技术在文化和旅游场景中的综合应用成效，重点覆盖以下四个一级指标：

- 技术赋能效能
- 游客感知体验
- 文化价值传播
- 经济社会增值

问卷结果可用于：

- 形成 `target_score` 监督标签
- 支撑专家评价与人工综合评分
- 作为模型训练和效果验证的统一评分依据

## 2. 适用对象

适用于以下被调查者：

- 景区游客
- 博物馆观众
- 数字导览服务使用者
- 智能讲解、问答、推荐系统体验者

## 3. 量表设计

本问卷采用 5 级 Likert 量表。

| 选项 | 分值 | 含义 |
| --- | --- | --- |
| 非常不同意 | 1 | 体验或认知明显不符合 |
| 不同意 | 2 | 基本不符合 |
| 一般 | 3 | 感受中性 |
| 同意 | 4 | 基本符合 |
| 非常同意 | 5 | 明显符合 |

说明：

- 所有题项默认按正向计分
- 分数越高，表示 AI+文旅应用成效越好

## 4. 一级指标与权重

建议采用以下一级指标权重：

| 一级指标 | 代码 | 权重 |
| --- | --- | --- |
| 技术赋能效能 | `tech_empowerment` | 0.25 |
| 游客感知体验 | `visitor_experience` | 0.30 |
| 文化价值传播 | `cultural_value` | 0.25 |
| 经济社会增值 | `economic_social_gain` | 0.20 |

说明：

- 该权重适合课题原型与实验阶段使用
- 若后续组织专家咨询，也可对权重进一步校准

## 5. 问卷题项设计

每个一级指标设置 5 个题项，共 20 个评分题；第 21 题为开放反馈题。

### A. 技术赋能效能

1. 这项 AI 文旅服务容易找到、容易启动，我不需要花费太多时间寻找入口。
2. 第一次使用这项服务时，我很快就学会了基本操作。
3. 这项服务响应及时、运行稳定，很少出现卡顿、掉线或重复操作。
4. 这项服务提供的信息、讲解、识别、推荐或执行结果准确可信。
5. 这项服务与当时的场所、游览流程和我的实际需要相匹配。

维度解释：

- 衡量 AI 系统是否真正改善服务效率、交互质量与场景适配性

### B. 游客感知体验

6. 这项服务减少了我在游览、参观或住宿中的操作负担，使过程更轻松。
7. 使用过程中，我能自主决定节奏和关注内容，不容易感到困惑或失去控制。
8. 这项服务增强了我对现场空间、展项、故事或目的地的沉浸感。
9. 这项服务使本次体验更有趣，激发了我的好奇心和继续探索的愿望。
10. 这项服务让我与人物、故事、地方或同行者产生了更强的情感联系。

维度解释：

- 衡量游客主观体验、满意度、沉浸感和持续使用意愿

### C. 文化价值传播

11. 这项服务帮助我理解了具体的历史事件、人物、技艺或文化概念。
12. 这项服务帮助我把零散信息联系到更完整的历史、地域或社会背景中。
13. 体验结束后，我还能回想起至少一个通过这项服务新了解到的具体文化知识点。
14. 这项服务尊重史实和文化语境，能够体现真实的地方特色，没有明显歪曲或过度简化。
15. 体验后，我更愿意继续学习、保护、参与相关文化活动，或向他人介绍这些文化内容。

维度解释：

- 衡量文化理解、知识获取、传播深度与教育价值

### D. 经济社会增值

16. 这项服务提高了我在有限时间内获得有效体验的效率，减少了排队、迷路或无效移动。
17. 这项服务让不同年龄、语言或身体条件的人更容易参与文旅活动。
18. 这项服务增强了我延长停留、参与餐饮、文创、演出等延伸消费或为有价值服务付费的意愿。
19. 如果下次再次到访，我愿意继续使用这项服务，并愿意向亲友推荐它。
20. 总体而言，这项 AI 文旅服务明显改善了我的体验，并提升了我对该场所文旅服务价值的认可。

维度解释：

- 衡量品牌传播、推荐意愿、消费促进与社会影响

## 6. 评分计算规则

### 6.1 一级指标得分

每个一级指标由 5 个题项组成，先计算该维度平均分，再换算为百分制。

计算公式：

```text
一级指标得分 = (该维度题项平均分 / 5) × 100
```

例如：

- 技术赋能效能 5 个题项得分分别为 `4, 5, 4, 3, 4`
- 平均分为 `4.0`
- 百分制得分为：

```text
(4.0 / 5) × 100 = 80
```

### 6.2 问卷总分

问卷总分采用加权汇总：

```text
问卷总分 =
0.25 × 技术赋能效能 +
0.30 × 游客感知体验 +
0.25 × 文化价值传播 +
0.20 × 经济社会增值
```

最终总分范围为 `0-100`。

### 6.3 可直接作为 target_score

若问卷是当前样本的主要标签来源，则：

```text
target_score = 问卷总分
```

## 7. 结果解释标准

建议对总分划分为以下等级：

| 总分区间 | 等级 | 解释 |
| --- | --- | --- |
| 90-100 | 优秀 | AI+文旅应用成效非常突出 |
| 80-89 | 良好 | 整体表现较强，具备明显应用价值 |
| 70-79 | 中上 | 成效较明显，但仍有优化空间 |
| 60-69 | 一般 | 有一定作用，但体验或价值传播仍不足 |
| 0-59 | 较弱 | 应用成效不明显，需要重点改进 |

## 8. 数据入库建议

如果你要把问卷结果接入当前项目，建议保存以下字段：

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `q1` - `q20` | int | 原始评分题分值，范围 1-5 |
| `review_text` | string | 第 21 题开放反馈文本 |
| `tech_empowerment` | float | 一级指标百分制得分 |
| `visitor_experience` | float | 一级指标百分制得分 |
| `cultural_value` | float | 一级指标百分制得分 |
| `economic_social_gain` | float | 一级指标百分制得分 |
| `target_score` | float | 问卷总分，范围 0-100 |

说明：

- 如果你的 CSV 中已经保留一级指标列，那么问卷结果可以直接填入这些字段
- `target_score` 可由上述四个一级指标加权计算得到

## 9. 推荐发放方式

建议采用以下问卷发放场景：

- 游客完成参观后即时填写
- 体验智能导览/问答服务后填写
- 活动结束后统一采集
- 访谈结束后由研究人员辅助录入

建议每份问卷同时记录以下辅助信息：

- 调查时间
- 调查地点
- 场景类型
- 是否使用 AI 导览
- 是否使用智能问答
- 是否首次到访

这些字段可以单独保存，不一定直接参与模型训练，但有助于后续分析。
